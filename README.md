Cả nhóm sửa cùng file `index.html`. Mỗi khối nằm giữa một cặp comment `MEMBER-x:START` và `MEMBER-x:END`. Chỉ sửa bên trong cặp của mình, không format cả file, để Git gộp nhánh mà không đụng nhau.
